- Created at: 2026-07-01 15:39:18
- Branch: dev/API+Tran

## Purpose

개발팀이 추가한 크롤러 설정 카테고리 구조에 맞춰, 사용자가 직접 테스트하며 조정한 CR/GR 관련 설정 변경분을 `dev/API+Tran` 브랜치에 반영한다.

## Why This Change Was Needed

CR/GR 카테고리 항목을 설정 저장 후 수동 실행해 보니, 각 항목이 `search_term` 페이지 파라미터와 `filter_term` 필터어를 기준으로 수집되는 구조가 확인됐다. 운영 브랜치에서도 동일한 설정을 사용할 수 있도록 로컬에서 검증한 설정 JSON 변경분을 커밋한다.

커밋 전 원격 확인 결과 `origin/dev/API+Tran`에 새 커밋 2개가 있었다.

- `9d9764c Add grouped news summary counts`
- `e05826c Add news list summary counts`

두 커밋은 `crawler_app/news_sqlite_store.py`, `news-ui-api-interface-definition.md`, `static/news_review_ui/app.js`를 수정했고, 로컬 설정 JSON 변경과 충돌하지 않아 `git pull --ff-only origin dev/API+Tran`으로 먼저 반영했다.

## Design Judgment

이번 변경은 사용자 편집 가능 설정 영역이다. 중복 URL 정규화, 검색엔진 본문 추출, SQLite schema 같은 소스코드 변경은 이번 push 범위에서 제외했다. 개발팀 요청은 현재 테스트한 설정을 브랜치에 보존하는 것이므로, JSON 설정만 선택적으로 stage한다.

## Alternatives Considered Or Deferred

- URL 정규화 로직 변경: 민주당/국민의힘 일부 게시판에서 `sno`/`page` 파라미터 때문에 같은 기사로 보이는 URL이 별도 수집되는 문제가 보였지만, 소스코드 변경이 필요하므로 이번 설정 push에서는 제외했다.
- 구글/네이버/다음 본문 추출: `newspaper3k` 기반 본문 수집은 별도 설계와 저장 정책 검토가 필요한 기능 변경이므로 이번 설정 push에는 포함하지 않았다.
- SQLite 초기화/재적재: 이번 변경은 설정 파일 반영이 목적이므로 DB 산출물은 커밋하지 않는다.

## Validation

- `git fetch origin dev/API+Tran`: 원격 새 커밋 확인.
- `git pull --ff-only origin dev/API+Tran`: 원격 summary count 관련 변경 fast-forward 반영.
- 18개 변경 설정 파일을 Python `json.loads`로 파싱해 JSON 문법 정상 확인.
- 검증 결과:
  - `JSON_OK 18`
  - CR/GR 대상 설정의 `category`, `search_terms`, `filter_terms` 개수 확인.
- 산출물 검수에서 `workflow_records.json`의 `search_term`, `filter_term` 배열 저장과 필터어 매칭이 정상 동작하는 것을 확인했다.

## Remaining Risks

- 현재 설정 변경은 사용자가 수동 테스트한 로컬 설정 기준이다. 원격에서 새로 들어온 UI/API summary count 변경과 기능적으로 직접 충돌하지 않지만, 운영 UI에서 카테고리 문자열(`GR,PR`)을 어떻게 해석하는지는 별도 확인이 필요하다.
- 같은 기사지만 URL의 `sno`/`page` 파라미터가 다른 경우는 현재 설정만으로 해결하지 않는다.
- SQLite에는 과거 실행 데이터가 누적될 수 있으므로, 설정 검수 시 현재 `workflow_records.json`과 DB row 수가 항상 1:1로 같지는 않을 수 있다.

## Cumulative Prompt / Request Flow

사용자는 CR/GR 카테고리 항목들을 설정 저장한 뒤 수동 실행을 두 번 진행했고, 결과물 기준으로 `search_term`, `filter_term`, 중복 진단, SQLite 적재 여부를 확인해 달라고 요청했다. 검수 결과 대체로 정상이나 URL 정규화가 필요한 일부 중복 가능성이 확인됐다. 사용자는 URL 정규화는 소스 변경 없이는 어렵다는 점을 확인한 뒤, 이번에는 테스트하며 바꾼 설정 파일만 push해 달라고 요청했다.
